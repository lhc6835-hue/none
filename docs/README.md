# 점선정원 : 씨앗 수비대 (DOTLINE GARDEN) — 게임 기획서

> **한 줄 소개**
> 할머니가 남긴 이상한 온실에서 점 두 개와 선 하나로 웃는 판타지 식물을 씨앗부터 키우고, 그 아이들을 꺾꽂이해 '잿빛 시듦' 군단으로부터 정원을 지키는 픽셀아트 육성 타워디펜스.

- 장르: 육성 시뮬레이션 + 경로형 타워디펜스 + 수집(도감 · 교배)
- 플랫폼: 웹(PC · 모바일 브라우저) 우선 → PC(Steam) / 모바일(앱 패키징) 확장
- 화면: 가로 16:9, 내부 해상도 640×360, 정수 배율 확대
- 과금: v1은 과금 없음(프리미엄 판매 전제). 모든 재화는 플레이로만 얻는다
- 분량 목표: 식물 100종(+색변이 100종) · 등급 8단계 · 적 34종 + 보스 7 · 스테이지 42개 × 난이도 5단계

## 확정된 핵심 결정 (바꾸려면 이 표부터 고칠 것)

| 항목 | 결정 | 이유 |
|---|---|---|
| 엔진 | TypeScript + Vite + Phaser 3 (최신 3.x 안정판) | 웹 배포가 쉽고, 픽셀아트 모드 · 트윈 · 파티클이 갖춰져 있으며 AI가 가장 안정적으로 다루는 조합 |
| 아트 제작 | **코드로 그리는 절차적 픽셀아트**(손으로 찍은 부품 스탬프 + 조합기) | 외부 이미지 없이 100종 × 6단계를 일관된 품질로 만들 수 있음. PNG 교체 훅 제공 |
| 얼굴 | 눈 = 점, 입 = 선. **런타임에 코드로 덧그림** | 표정 16종을 100종 모두에게 자동 적용, 불쾌한 골짜기 원천 차단 |
| 해상도 | 640×360, 타일 24px, 식물 스프라이트 24×32 | 16:9 모든 해상도에 정수 배율로 딱 맞음 |
| 폰트 | Galmuri(갈무리) 픽셀 폰트, SIL OFL | 한글을 지원하는 픽셀 폰트. 라이선스 파일 동봉 |
| 사운드 | ZzFX(효과음) + 자체 미니 시퀀서(배경음) | 음원 파일 없이 코드로 생성 |
| 전투 방식 | 경로형 TD(적이 길을 따라 이동) + 꺾꽂이 배치 | 키운 식물 한 그루가 '어미'가 되고, 전장에는 분신을 심는다 |
| 식물 죽음 | **없음**. 방치하면 시들고 기분이 상해 전투력만 떨어짐 | 펫 육성의 스트레스를 줄이고 애착을 지킴 |
| 인간 캐릭터 | 화면에 등장하지 않음(할머니는 편지로만, 플레이어는 손 커서) | 사람 얼굴에서 오는 불쾌한 골짜기 원천 차단 |

## 용어집 (모든 문서 · 코드 · UI에서 이 표기를 쓴다)

| 용어 | 뜻 | 코드 키 |
|---|---|---|
| 빛 등급 | 식물 · 씨앗의 희귀도 8단계(그늘 → 태초) | `grade` |
| 계열 | 식물의 10가지 전투 성향 묶음(덩굴, 가시, 버섯 …) | `family` |
| 성장 단계 | 씨앗 → 발아 → 새싹 → 어린잎 → 성숙 → 개화 | `stage` 0–5 |
| 성장치(GP) | 다음 단계로 가는 데 필요한 누적 수치 | `gp` |
| 욕구 | 수분 · 양분 · 청결 · 기분(0–100 게이지) | `needs` |
| 애정도 | 돌볼수록 쌓이는 친밀도(♡0–♡10) | `affection` |
| 자질 | 개화 순간 확정되는 품질 별(★1–★5) | `quality` |
| 형질 | 식물에 붙는 랜덤 특성. 교배로 유전됨 | `traits` |
| 색변이 | 1/64 확률의 희귀 색 개체 | `variant` |
| 각성 | 애정도 ♡10 + 각성 앰플로 레벨 상한 +10 | `awakened` |
| 꺾꽂이 | 전투에서 어미 식물의 분신을 심는 행위(= 타워 배치) | `deploy` |
| 양분 | 전투 중 쓰는 자원(배치 · 강화 비용) | `sap` |
| 뿌리 하트 | 전투의 생명. 적이 출구에 닿으면 깎임 | `hearts` |
| 개화기 | 전투 중 게이지가 차면 자동 발동하는 식물 필살기 | `bloomSkill` |
| 정원사 도구 | 플레이어가 전투 중 직접 쓰는 능력(소나기, 삽 …) | `tools` |
| 잎전 | 기본 재화 | `coin` |
| 맑은 이슬 | 희귀 재화 | `dew` |
| 관찰 노트 | 연구 재화(돌봄 · 발견으로 획득) | `notes` |
| 잿빛 시듦 | 적 세력. 생명을 잿빛으로 말려 버리는 역병 | `wilt` |
| 어미나무 | 정원의 심장. 진행도에 따라 자라는 거대한 나무 | `motherTree` |
| 점박이 | 무당벌레 안내자(마스코트) | `npc_ladybug` |
