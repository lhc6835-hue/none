# 10. 메인화면 · 화면 흐름 · 손맛(부드러움) · 튜토리얼 · 접근성

## 1. 메인화면 = 살아 있는 온실 (메뉴 목록이 아니다)

- 메인화면은 **가로로 2.5화면(1600×360)짜리 온실 한 채**다. 좌우로 끌거나(스와이프 · 마우스 드래그 · 휠) 화면 가장자리 화살표로 이동한다. 관성 스크롤 + 구역 경계에서 살짝 감속.
- **패럴랙스 4겹**: 하늘(0.2) · 먼 언덕과 숲(0.4) · 온실 본체(1.0) · 앞쪽 잎사귀 실루엣(1.2).
- 화면 안의 사물이 곧 메뉴다. 그래도 길을 잃지 않도록 아래쪽에 **빠른 메뉴 바**(출격 · 가방 · 도감 · 상점 · 꾸미기)를 항상 둔다.
- 할 일이 있는 사물에는 작은 `!` 배지가 통통 튄다(모양 · 색 · 움직임을 모든 사물에서 똑같이).

### 1-1. 구역 배치 (왼쪽 → 오른쪽)

```
x=0                320                         960            1280           1600
┌──────────────────┬───────────────────────────┬──────────────┬──────────────┐
│ 바깥 · 입구       │ 온실 본관                  │ 서재 구석     │ 뒤뜰 창 쪽    │
│ 우편함 · 야외 화단 │ 창가 선반 · 중앙 테이블     │ 책장(도감)    │ 어미나무 창   │
│ 정원 문(출격)     │ 그늘 구석 · 축음기         │ 연구 책상     │ 달빛 창 · 수조 │
│ 상인 수레 자리    │ 퇴비통 · 작업대 · 봉투 테이블│ 게시판 · 달력 │ 교배대 · 난로  │
│ 바람개비 · 울타리  │ 씨앗 상자 · 블라인드        │ 라디오 · 트로피│ 선풍기        │
└──────────────────┴───────────────────────────┴──────────────┴──────────────┘
```
- 처음 접속하면 온실 본관 가운데에서 시작하고, 다음부터는 마지막으로 보던 위치에서 시작한다.

### 1-3. 타이틀 화면
- 새벽빛이 드는 온실 한 장면. 선반 위 식물들이 깜빡이며 **커서를 눈으로 따라온다.**
- 로고 '점선정원'의 'ㅇ' 두 개가 눈(점)이 되고 그 아래 획이 입(선)이 되는 글자 디자인. 몇 초마다 로고가 깜빡인다.
- 버튼: 이어하기 · 새로 시작 · 설정 · 만든 사람들. 아무 데나 탭해도 이어하기.

## 2. 화면 흐름

```
부팅 → 로딩(씨앗이 싹트는 진행 바) → 타이틀 → 온실(메인)
온실 ─┬─ 돌보기(식물 하나, 월드 ×2)       ┬─ 도감 / 식물 일기
      ├─ 씨앗 심기 / 봉투 개봉              ├─ 연구 / 작업대 / 상점 / 상인
      ├─ 교배                              ├─ 우편 / 의뢰 / 출석
      ├─ 꾸미기 모드 / 사진 모드             └─ 설정
      └─ 정원 문 → 월드맵 → 스테이지 선택(난이도) → 출격 준비(덱) → 전투 → 결과
                                                               └→ 온실 / 다음 / 다시
```
- **월드맵**: 챕터 7개가 덩굴 길로 이어진 섬들처럼 펼쳐진 지도. 스테이지 노드는 화분 모양이고, 별 수와 최고 난이도가 꽃 색으로 표시된다. 잠긴 챕터는 잿빛 안개에 덮여 있다가 열릴 때 안개가 걷히는 연출.
- 큰 화면은 Phaser 씬으로, 작은 창(모달)은 하나의 UI 오버레이 씬에서 띄운다.

## 3. 손맛 · 부드러움 규칙 (모든 화면 공통)

| 항목 | 규칙 |
|---|---|
| 반응 속도 | 모든 입력은 **같은 프레임 안에** 소리와 시각 반응을 시작한다 |
| 버튼 | 호버: 1px 들림 + 밝은 외곽선 / 누름: 1px 내려감 / 뗌: 120ms 탄성 복귀(easeOutBack) |
| 창 열기 · 닫기 | 열기 160ms(크기 0.9→1 + 페이드, easeOutBack) · 닫기 120ms(easeInCubic) |
| 화면 전환 | **잎사귀 와이프**(잎들이 화면을 쓸고 지나감, 350ms) 또는 **흙 디졸브**(픽셀 디졸브, 300ms) |
| 숫자 | 재화 · 점수는 300ms 동안 굴러가며 바뀌고, 얻은 양은 `+120`처럼 떠올랐다 사라짐 |
| 대기 생명감 | **화면이 완전히 멈춰 있는 순간이 없게** 한다: 먼지 입자, 흔들리는 잎, 숨 쉬는 식물, 흐르는 구름 |
| 화면 흔들림 | 최대 2px, 150ms. 보스 큰 공격 · 큰 폭발에만. 설정에서 끌 수 있음 |
| 히트스톱 | 40ms. 보스 단계 전환, 보스 최대 HP 10% 이상의 한 방에만 |
| 이징 | 등장 easeOutBack, 이동 easeOutCubic, 대기 easeInOutSine. 선형 트윈 금지(진행 바 제외) |
| 로딩 | 반응 없이 1초 넘게 기다리게 하지 않는다. 진행 바나 애니메이션을 먼저 보여 줌 |
| 터치 판정 | 내부 해상도 16×16px 이상(모바일 ×3 배율이면 실제 48px 이상) |
| 정보 보기 | 모바일 길게 누르기 / PC 마우스 올리기 · 오른쪽 클릭 = 툴팁 |
| 실수 방지 | 확인 창은 되돌릴 수 없고 비싼 행동에만(맑은 이슬 50 이상, ★4 이상 식물 씨앗 판매). 나머지는 3초 '되돌리기' 버튼 |
| 실패 표현 | "양분이 부족해요" = 비용 숫자가 빨갛게 2번 흔들림 + 둔탁한 소리. 팝업 금지 |
| 말투 | 점박이는 다정한 해요체, 한 번에 2줄 이하. 식물은 글자 대신 기호 말풍선 |

## 4. 튜토리얼 (첫 15분)

원칙: **한 단계에 개념 하나**, 플레이어가 직접 손을 움직인다(구경만 하는 단계 없음), 말풍선은 2줄 이하.

| 단계 | 내용 | 끝나는 조건 | 목표 시각 |
|---|---|---|---|
| T0 | 새로 시작 → 그림 3장짜리 인트로(할머니 편지 글 + 낡은 온실 그림). 건너뛰기 가능 | 탭 | 0:30 |
| T1 | 먼지 쌓인 온실. 점박이가 날아와 인사, 손 커서 소개 | 점박이 탭 | 0:45 |
| T2 | 편지에 든 첫 씨앗(P011 따끔선인장)을 화분으로 끌어 심기 | 심기 완료 | 1:10 |
| T3 | 물뿌리개: 목표선 안내("선인장은 물을 조금만 좋아해요!"). 이 단계에서는 실패해도 다시 시도 | 완벽 판정 | 1:40 |
| T4 | 튜토리얼 전용 뼛가루를 흔들어 뿌림 → 발아 → 새싹 → **처음 눈뜨기** → 이름 짓기 | 이름 확정 | 2:50 |
| T5 | 곰팡이 점이 생김 → 솔로 닦기 → 간지럼 반응 | 곰팡이 제거 | 3:30 |
| T6 | 쓰다듬기 → 기쁨 + 애정도 하트 | 쓰다듬기 1회 | 4:00 |
| T7 | 뼛가루 한 번 더 → 어린잎. "이제 함께 싸울 수 있어요!" 점박이가 정원 문을 가리킴 | 정원 문 탭 | 5:00 |
| T8 | 1-1 전투: 카드 끌어 심기(튜토리얼 동안 일시정지 안내), 웨이브 시작, 강화 1번 | 승리 | 8:00 |
| T9 | 결과 화면 → 흙 봉투 + P031 꿀단지 민들레 씨앗 → **봉투 개봉 연출** 체험 | 개봉 완료 | 9:30 |
| T10 | 온실로 돌아와 민들레 심기, P001 꼬불덩굴 선물(점박이), 게시판의 일일 의뢰 소개 → 자유 플레이 | 의뢰 확인 | 12:00 |

- 이후 기능은 해금될 때 그 자리에서 짧게 한 번만 알려 준다(예: Lv3이 되면 첫 벌레가 나타나며 핀셋 안내).
- 튜토리얼 중에는 욕구 감소를 멈추고, 실패해도 손해가 없게 만든다.

## 5. 접근성 · 설정

| 분류 | 항목 |
|---|---|
| 소리 | 전체 · 배경음 · 효과음 · **식물 콧노래** 음량 따로, 모바일 진동 |
