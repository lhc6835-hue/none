# 결정 기록

## 2026-11-13 — 정식 개발 시작 (M1)
- 시제품(블록 → 액체)을 버리고 새 구조로 다시 시작. 액체는 한 종류만.
- 굳는 속도: 시제품 약 1.2초 → 0.25초(최대 0.7초). 요청에 따라 더 빠르게.
- 발사 방식: 점점이 날아가는 덩어리 → 끊기지 않는 물대포. 물방울을 매 틱 두 줄로 쏘고 이웃끼리 굵은 선으로 이어 그린다.
- 물줄기 중력을 0.13 → 0.065로 낮춤: 처음 값으로는 150px 떨어진 벽을 겨눠도 34px나 처져서 다리를 놓을 수 없었다.
- 물방울당 수액 3칸 → 5칸, 아래·옆부터 고이도록 변경: 다리가 너무 가늘고 삐죽했다.
- 적의 낭떠러지 감지를 발밑 5칸까지 보게 변경: 호박 바닥의 작은 구멍 때문에 제자리에서 맴돌았다.
- pixelfx(MIT)는 `.claude/skills/pixelfx`에 스킬로만 설치하고, 게임 코드에는 소스를 가져오지 않았다. 두 버퍼 합성·바이어 디더·단계 팔레트·입자 연출 원리만 참고해 직접 구현했다.
- 빌드는 esbuild로 묶어서 `dist/index.html` 한 파일로 만든다(다운로드해서 바로 실행 가능).
