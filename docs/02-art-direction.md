# 02. 아트 디렉션 — 픽셀 규칙 · 점선 얼굴 · 절차적 스프라이트

> 목표: 외부 이미지 파일 없이 **코드로 생성해도 손으로 찍은 것처럼 보이는** 일관된 픽셀아트.
> 이 문서의 규칙은 '권장'이 아니라 '검수 기준'이다. 디버그 갤러리에서 자동 검사한다.

## 3. 명암 · 외곽선 · 디더링

- 광원: **왼쪽 위 고정**. 위 · 왼쪽 면은 3번, 기본면은 2번, 아래 · 오른쪽 면은 1번 색. 4번은 부위당 1–2px 하이라이트에만 쓴다.
- 외곽선: 1px. **선택적 외곽선**을 쓴다. 바깥 외곽선은 그 부위 램프의 0번 색이고, 부위끼리 맞닿는 경계는 더 어두운 쪽 부위의 1번 색이다. 순검정 외곽선 금지.
- 디더링: 배경 · 하늘 · 물에서만, 2색 체크 패턴으로. 캐릭터 몸에는 금지.
- 고아 픽셀(이웃 없는 1px), 계단이 들쭉날쭉한 곡선(1-2-1-3 같은 불규칙 계단) 금지. 곡선 계단은 3-2-1-1-2-3처럼 규칙적으로 바뀌어야 한다.
- 반투명: 영혼 계열 몸통에 한해 70% 불투명도 허용. 얼굴은 항상 100%.

## 5. 점선 얼굴 규칙 ★핵심★

### 5-1. 절대 규칙
1. 얼굴 요소는 **눈과 입뿐**이다. 코 · 눈썹 · 귀 · 볼터치 · 이빨 · 혀 · 눈동자 하이라이트 · 속눈썹 · 주름은 금지.
2. **눈 = 점.** 기본 1×1px. 몸 폭이 48px 이상인 보스만 2×2px. 표정이 바뀔 때만 2–3px짜리 선 모양으로 잠깐 바뀐다.
3. **입 = 선.** 두께 1px. 직선 · 꺾은선 · 물결선 · 한 점만 쓴다. 입 안을 색으로 채우는 것은 금지. 벌린 입은 평행선 두 줄(`=`)로 표현한다.
4. 잉크색은 몸 색과 명도 대비가 3:1 이상이어야 한다. 밝은 몸에는 잉크(`#14121a`), 어두운 몸에는 종이(`#fdfbf5`)를 자동으로 고른다.
5. 얼굴은 몸 스프라이트 위에 **런타임으로 덧그린다**(5-6 참고). 몸 스프라이트에 얼굴을 그려 넣지 않는다.
6. 사람 비례 금지: '둥근 머리 + 목 + 어깨' 위에 얼굴을 얹는 구도를 쓰지 않는다. 얼굴은 구근 · 꽃 중심 · 열매 · 버섯 갓 · 줄기 · 잎에 붙인다.

### 5-2. 과장 비율 수치 (검수기가 자동 판정)
얼굴이 붙는 부위(호스트)의 폭을 W, 높이를 H라고 한다.

| 항목 | 허용 A | 허용 B | **금지 구간(사람 비율)** |
|---|---|---|---|
| 두 눈 사이 거리 D | D ≥ 0.6W (넓은 미간) | D = 2 (사이에 1px만 둔 붙은 눈) | 3 ≤ D < 0.6W |
| 입 길이 L | L ≥ 0.5W (긴 입) | L = 1 (점 입) | 2 ≤ L < 0.5W |
| 눈과 입의 세로 간격 V | V = 1 (바로 아랫줄) | V ≥ 0.4H (멀리 떨어짐) | 그 사이 |
| 호스트 최소 폭 | W ≥ 8 | — | W < 8이면 눈 1개 + 점 입만 허용 |

- 기준 값(평상시 표정)에서만 판정한다. 표정이 바뀌는 순간에는 잠깐 벗어나도 된다.
- 눈은 외곽선 위에 놓이면 안 되고, 반드시 몸 안쪽 픽셀에 놓는다.

### 5-5. 살아 있는 느낌을 주는 얼굴 동작
- **시선 추적**: 눈 점이 커서 · 들고 있는 도구 · 가장 가까운 적 쪽으로 최대 1px 움직인다. 이것만으로도 생동감이 크게 산다.
- **기대 반응**: 물뿌리개를 든 커서가 4타일 안으로 오면 목마른 식물은 입을 `=`로 벌리고 몸을 1px 기울인다.
- **눈 깜빡임 동기화 금지**: 모든 식물의 깜빡 타이머를 무작위로 엇갈리게 둔다.
- **처음 눈뜨기**: 발아 → 새싹으로 넘어갈 때 한 번만, 가로선 눈이 0.6초에 걸쳐 점으로 열린다(놀람 표정 + 효과음 '뾰옹'). 이 게임의 대표 연출이다.

### 5-6. 구현: FaceRenderer
- 몸 스프라이트의 프레임마다 `faceHost: {x, y, w, h}`를 메타데이터로 기록한다. 숨쉬기나 흔들림으로 몸이 움직이면 얼굴도 그대로 따라간다.
- `FaceRenderer.draw(target, faceSpec, expression, lookDir, ink)`가 정수 좌표에 1px 사각형으로 눈과 입을 그린다.
- 같은 얼굴 레이어를 식물 · 적 · NPC가 모두 공유한다.
- **얼굴 검수기**(디버그): 모든 종 × 단계에서 5-2 수치를 검사해 위반하면 빨간 테두리로 표시하고, 빌드 테스트에서 실패 처리한다.

### 5-7. 적 얼굴 규칙
- 규칙은 같다. 다만 기본 표정은 '전투'(사선 눈)나 '멍함'(점 눈 + 물결 입)이다.
- 적의 잉크색은 종이색 대신 `#f8a577`(R7-4)을 써서 식물과 구분한다.
- 보스는 체력 단계가 바뀔 때 표정이 바뀐다(분노 → 당황 → 기절).

## 7. 절차적 스프라이트 생성 파이프라인

```
종 데이터(look) → ① 스켈레톤 → ② 부품 스탬프 배치 → ③ 자동 명암 → ④ 선택적 외곽선
  → ⑤ 정리(고아 픽셀 제거) → ⑥ 프레임 생성 → ⑦ 텍스처 아틀라스 등록 → 얼굴은 런타임에 덧그림
```

1. **부품 스탬프 라이브러리**(손으로 찍은 ASCII 픽셀맵, 60개 이상): 잎(둥근 · 뾰족 · 하트 · 바늘 · 깃털 · 넓적), 꽃잎(3 · 4 · 5 · 6장), 버섯 갓 4종, 가시 3종, 열매 6종, 덩굴손 4종, 결정 3종, 구근 4종, 줄기 마디, 씨앗 10종(계열별).
   - 스탬프 문자: `.` 빈칸, `M` 주 램프, `S` 보조 램프, `A` 강조 램프, `h` 강제 하이라이트, `d` 강제 그림자, `L` 발광(명암 계산 제외).
   - 예시(둥근 잎 7×5):
     ```
     ..MMM..
     .MMMMM.
     MMMhMMM
     .MMMMd.
     ..MM...
     ```
2. **스켈레톤**: 바디 플랜마다 기준점(화분 테 중심), 줄기 곡선, 부품 부착점을 정의한다. 단계마다 크기 표(4절)에 맞게 늘린다. 대부분 좌우 대칭이되, 잎 하나 정도는 1px 어긋나게 해서 귀여움을 준다.
3. **자동 명암**: 기본 2번 색 → 왼쪽 위가 비어 있으면 3번 → 오른쪽 아래가 비어 있으면 1번 → 부위 경계는 1번. 4번 하이라이트는 부위마다 왼쪽 위에 1–2px.
4. **결정적 난수**: 종 ID를 시드로 쓰는 난수 생성기를 써서 실행할 때마다 똑같이 생성한다.
5. **프레임**(종 × 단계마다):
   - 대기 4프레임: 윗부분만 좌우 ±1px 흔들림 + 1px 숨쉬기
   - 공격 3프레임: 웅크림(가운데 1줄 제거) → 뻗음(1줄 복제) → 복귀
   - 피격 1프레임: 전체를 4번 색으로 번쩍
   - 시듦 1프레임: 윗부분 1–2px 아래 · 바깥으로 처짐 + 채도 낮춤
   - 잠 1프레임: 살짝 처짐 + 한 단계 어두운 색
6. **지연 생성**: 부팅할 때는 보유한 종과 UI에 필요한 것만 생성한다. 나머지는 처음 필요할 때 만들어 캐시한다. 디버그 갤러리에서만 전체를 생성한다.
7. **교체 훅**: `public/art/plants/{ID}_{stage}.png`가 매니페스트에 있으면 생성 대신 그 파일을 쓴다(나중에 손그림 아트로 갈아 끼우기 위함).

## 10. 이펙트 규격

| 이펙트 | 크기 | 수명 | 수량 상한 |
|---|---|---|---|
| 물방울 | 2×3 | 0.5초(포물선) | 돌봄 1회당 12개 |
| 반짝 | 3×3 십자 | 0.3초 | 등급 연출 8개 |
| 포자 | 2×2 | 1.2초(위로 떠오름) | 장판당 6개 |
| 불씨 | 1×2 | 0.8초 | 화상 대상당 2개 |
| 눈송이 | 3×3 | 1초 | 〃 |
| 피격 숫자 | 3×5 숫자 | 0.6초(위로 6px + 페이드) | 화면 전체 40개, 넘으면 합산 표시 |
| 하트 · 음표 · z | 5×5 · 4×5 · 3×3 | 1초 | 식물당 3개 |

- 이펙트도 팔레트 색만 쓴다. 가산 블렌딩은 빛 · 불꽃 · 등급 오라에만 쓴다.
- 설정의 '번쩍임 줄이기'를 켜면 화면 섬광을 끄고 이펙트 밝기를 60%로 낮춘다.
