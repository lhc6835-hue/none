# 서드파티 라이선스

이 게임은 아래 오픈소스를 사용합니다. 각 라이선스 전문은 해당 프로젝트 또는 동봉 파일에서 확인할 수 있습니다.

| 이름 | 용도 | 라이선스 | 위치 |
|---|---|---|---|
| [Phaser 3](https://phaser.io) (3.90.0) | 게임 엔진 | MIT | npm `phaser` |
| [ZzFX](https://github.com/KilledByAPixel/ZzFX) (1.4.0, © 2019 Frank Force) | 효과음 생성 | MIT | `src/audio/zzfx.ts` (라이선스 주석 유지) |
| [Galmuri 갈무리](https://galmuri.quiple.dev) (2.40.3, © 2019–2025 Lee Minseo) | 픽셀 글꼴 | SIL OFL 1.1 | `public/fonts/*.woff2`, 라이선스 `public/fonts/OFL.txt` |
