# 굳는 액체 시제품

쏜 액체가 흐르다가 굳어서 길도 되고 벽도 되는 2D 액션 게임 시제품이에요.

## 실행
`index.html`을 브라우저로 열면 바로 돼요. 설치할 건 없어요.

## 조작
- A/D 또는 ←/→: 이동
- W, 스페이스 또는 ↑: 점프 (길게 누르면 더 높이 뛰어요)
- 마우스: 조준 (점선으로 날아갈 길이 보여요)
- 왼쪽 클릭: 액체 발사 (누르고 있으면 연사)
- R: 처음부터

## 들어 있는 것
- **액체 한 종류:** 쏘면 끈적하게 흐르다가 1초쯤 뒤에 굳어요. 굳기 직전에는 반짝여요.
- **벽에 붙음:** 벽이나 굳은 덩어리 옆면에 쏘면 달라붙어서 발판이 돼요.
- **시간이 지나면 부서짐:** 굳은 덩어리는 40초쯤 버티고, 부서지기 전에 금이 가요.
- **액체 탱크:** 쏠 때마다 줄고 쉬면 다시 차요.
- **돌진하는 적:** 벽에 부딪히면 기절하고, 얇은 벽은 깨요.
- **포탑:** 탄을 쏘고, 그 탄은 굳은 벽을 깎아요.
- **굳히기:** 적을 세 번 맞히면 통째로 굳어서 발판이 돼요.
- **레벨 하나:** 낭떠러지 두 개, 절벽, 높은 벽을 지나 깃발까지 가요. 중간에 체크포인트가 있어요.
